Snabba steg (per operativsystem)

Ladda först ned installationsskriptet, läs igenom det och kör det sedan. Välj ditt operativsystem nedan.

På macOS och Linux visar less skriptet så att du kan läsa det – avsluta med q.

macOS

curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Ubuntu / Debian

sudo apt update && sudo apt install -y curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Fedora / RHEL

sudo dnf install -y curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Arch Linux

sudo pacman -S --needed curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Andra Linux-distributioner

curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Windows (PowerShell)

Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.ps1 -OutFile install.ps1
notepad .\install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1

Snabbtest i en virtuell maskin (VM)

  1. Gå till projektmappen i en terminal och starta en lokal webbserver:
    python3 -m http.server 8000
  2. Öppna sidan i webbläsaren:
    http://localhost:8000/download_sv.html
  3. Klicka på nedladdningsknapparna och kontrollera att filerna hamnar i nedladdningsmappen (Downloads).
  4. Stoppa webbservern med Ctrl+C när du är klar.
