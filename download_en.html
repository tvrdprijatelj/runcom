runcom — Installer

Download the installer assistant. It downloads the newest release, creates a Python virtual environment, and installs dependencies if needed.

Download install.sh (Linux / macOS) Download install.ps1 (Windows)

Quick steps (by operating system)

macOS

curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Ubuntu / Debian

sudo apt update && sudo apt install -y curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Fedora / RHEL

sudo dnf install -y curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Arch Linux

sudo pacman -S --needed curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Other Linux

curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Windows (PowerShell)

Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.ps1 -OutFile install.ps1
notepad .\install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1

Quick test in a VM

  1. Open a terminal in the project folder and run:
    python3 -m http.server 8000
  2. Open this page in a browser:
    http://localhost:8000/download_en.html
  3. Click the download buttons and check that the files end up in your Downloads folder.
  4. Stop the server with Ctrl + C when you are done.
