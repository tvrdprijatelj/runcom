runcom — Installer

Download the installer assistant. This script fetches the latest release, creates a Python virtual environment, and installs dependencies if needed.

 

What the installer does

  • queries GitHub for the newest release
  • downloads the release archive
  • creates a Python virtual environment
  • installs pip dependencies from requirements.txt if present
  • asks before installing system Python if it is missing

Recommended usage

curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

# Windows PowerShell
Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.ps1 -OutFile install.ps1
notepad .\install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1

Security notice

Do not run remote scripts without inspecting them first. The installer asks before performing system-level package installs.
