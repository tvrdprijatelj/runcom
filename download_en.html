runcom — Installer

Download the installer assistant. This script fetches the latest release, creates a Python virtual environment, and installs dependencies if needed.

 

Quick steps

  1. Download and open (Linux / macOS) 
    curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
  2. Run (Linux / macOS) 
    bash install.sh
  3. Download and open (Windows PowerShell) 
    Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.ps1 -OutFile install.ps1
notepad .\install.ps1
  4. Run (Windows) 
    powershell -ExecutionPolicy Bypass -File .\install.ps1

Quick test in a VM

  1. In the project folder run: 
    python3 -m http.server 8000
  2. Open a browser to: 
    http://localhost:8000/download_en.html
  3. Click the download buttons and check your Downloads folder.
