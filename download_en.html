runcom — Installer

Download the platform installer (assistant). Run the installer on your machine — it will fetch the latest release, install Python if needed, and set up the assistant.

How it works

The downloaded installer is a small script (shell or PowerShell). When you run it, it:

  • queries GitHub for the latest release of this repository and downloads it
  • extracts the release and creates a Python virtual environment
  • installs pip dependencies from requirements.txt (if present)
  • optionally attempts to install Python 3 using common OS package managers (apt/dnf/pacman/homebrew/winget/choco) if Python is missing — you will be asked before any system-level install is performed

Recommended one-line commands (OPTIONAL)

If you prefer running the installer directly from the web (less safe), use one of these commands after reviewing the script content:

curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
# then inspect: less install.sh
bash install.sh

# Windows PowerShell (inspect first):
Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.ps1 -OutFile install.ps1
# Then open in editor and run: powershell -ExecutionPolicy Bypass -File .\install.ps1

Security notice

Do not run remote scripts without inspecting them. The installer will prompt before installing system-level packages and will not silently modify system Python without consent.

If you want automatic install (no prompts)

The installer supports options to attempt automatic Python installation — however this requires administrator/root privileges and may change system packages. Use with care and only if you trust the source.
