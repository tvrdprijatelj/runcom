Uninstall Runcom — step by step

        
Choose your Linux distribution or operating system. The app, its Python environment and associated shortcuts are removed. Your own scripts, including ~/skript and extra files in the installation folder, are preserved.

          If Python, Bash or curl is missing
          

          

          
Install these tools only if they are missing, then retry the uninstall commands. The Linux uninstaller needs no pip packages or Tkinter.

        

        

          I chose a custom installation folder
          
The installed menu shortcut remembers the folder. For manual removal, specify the same folder used during installation. Replace the example path below with your actual path.

          
RUNCOM_INSTALL_DIR="/path/to/runcom" bash runcom-uninstall.sh

          
Linux/macOS default: ~/.local/share/runcom, or $XDG_DATA_HOME/runcom when configured. Windows default: %LOCALAPPDATA%\Runcom.

        

        

          How do I know it worked?
          
The terminal reports that Runcom was uninstalled. App files and associated shortcuts should be gone. Folders containing your own files are kept, with a message explaining this. Search the application menu again; log out and back in if your desktop still shows an old entry.

        

        

          Common uninstall problems
          
    
            
  • Cancelled: nothing is removed if you answer n or just press Enter.
    • 
            
  • Not a Runcom installation: check the path. The script refuses to remove an unrecognized folder.
    • 
            
  • Shortcut missing: use the download commands. You do not need to reinstall first.
    • 
            
  • Extra files kept: your files were intentionally preserved. Inspect the folder before removing anything else.
    • 
            
  • Permission denied / Access denied: close the app and check that you are using the account that installed it.
    • 
            
  • Linked-directory error: a linked installation may need manual handling. The uninstaller does not choose another folder for you.
