Installation

Choose your operating system

Choose the current fixes on main or the latest published release. The app is saved in your user directory. Run the installer again to update.

  1. Install prerequisites if needed.
  2. Download and inspect the installer.
    Download installer
  3. Fetch a fresh installer and run it from your terminal.


Manual launch and troubleshooting
You can also download the source and run python3 runcom.py (Windows: py runcom.py). Install Tkinter through your system, not pip. Use the terminal (F6) for scripts that ask for input or passwords.
