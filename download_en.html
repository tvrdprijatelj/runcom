Quick steps (by operating system)

First download the install script, review it, then run it. Pick your operating system below.

On macOS and Linux, less lets you read the script – press q to exit.

macOS

curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Ubuntu / Debian

sudo apt update && sudo apt install -y curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Fedora / RHEL

sudo dnf install -y curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Arch Linux

sudo pacman -S --needed curl
curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Other Linux distributions

curl -fsSL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o install.sh
less install.sh
bash install.sh

Windows (PowerShell)

Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.ps1 -OutFile install.ps1
notepad .\install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1

Quick test in a VM

  1. In a terminal, go to the project folder and start a local web server:
    python3 -m http.server 8000
  2. Open this address in a browser:
    http://localhost:8000/download_en.html
  3. Click the download buttons and check that the files end up in your Downloads folder.
  4. Stop the web server with Ctrl+C when you are done.
