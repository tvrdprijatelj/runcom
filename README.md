# Runcom – underhåll

Den här branchen visar underhållssidan via GitHub Pages.

Öppna Settings → Pages och välj Deploy from a branch som Source.

- Vanlig webbplats: main och / (root).
- Underhåll: maintenance och / (root).

Klicka Save efter varje byte. Vänta tills GitHub Pages har publicerat klart.

Underhållssidan finns även på de vanliga nedladdnings- och hjälpadresserna. Okända adresser visar samma innehåll med HTTP-status 404.

Ändringar på main påverkar inte den här branchen. Slå inte ihop maintenance med main.
