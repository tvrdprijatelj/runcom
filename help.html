Öppna hjälpen i appen med F1.

1. Vad är Runcom?

Runcom är en skripteditor för att skapa, öppna, ändra, spara och köra skript. Till vänster visas filerna i vald mapp, till höger skriver du kod och längst ned visas programmets utdata. Appens menyer är på svenska.

Du behöver inte installera några externa Python-paket för själva appen. Python måste däremot ha Tkinter, som används för det grafiska fönstret. Kommandona i dina egna skript kan kräva andra program eller paket.

SystemSkript som kan köras
Linux och macOSPython (.py), Bash (.sh, .bash) samt textskript med en giltig shebang.
WindowsBatch (.bat, .cmd), PowerShell (.ps1) och Python (.py).

En shebang är första raden i ett Unix-skript, exempelvis #!/usr/bin/env bash. Den anger vilket program som ska tolka skriptet. Runcom respekterar den för skal- och andra textskript. Python-filer körs med appens Python-miljö.

2. Installera på ditt operativsystem

Börja på nedladdningssidan. Välj operativsystem och version. Aktuella rättningar (main) hämtar aktuell källkod; Senaste publicerade release hämtar senaste publicerade utgåvan, som kan vara äldre. Installationsskripten utan versionsargument väljer release.

Arch Linux

Öppna en terminal. Installera Python, Tk och curl om de saknas. Kommandot nedan uppdaterar även systemet enligt Archs vanliga fullständiga uppdateringsflöde.

sudo pacman -Syu --needed python tk curl

Ubuntu och Debian

sudo apt update
sudo apt install python3 python3-venv python3-tk curl

Fedora

sudo dnf install python3 python3-tkinter python3-pip curl

Linux och macOS: hämta och kör installationen

  1. På macOS: installera först Python 3.8 eller senare med Tcl/Tk från python.org. På övriga Linux-system installerar du Python, Tkinter, venv och curl via systemets pakethanterare.
  2. Hämta ett nytt installationsskript till ett fast filnamn. Då undviker du att råka köra ett gammalt install.sh i din nedladdningsmapp.
curl -fL https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.sh -o runcom-install.sh

Öppna filen i din texteditor om du vill läsa igenom den. Kör sedan ett av följande alternativ:

# Aktuell källkod med de senaste rättningarna:
bash runcom-install.sh --ref main

# Eller: senaste publicerade release:
bash runcom-install.sh

Installationen hämtar arkivet, kontrollerar dess innehåll, skapar en Python-miljö och installerar deklarerade Python-beroenden om sådana finns. Den ersätter programmet först efter förkontrollerna. Den visar sedan ett startkommando.

Windows

  1. Installera Python 3.8 eller senare från python.org. Ta med Tcl/Tk och Python launcher. Öppna ett nytt PowerShell-fönster efter installationen.
  2. Kontrollera att Python och Tkinter fungerar:
py -3 -c "import sys, tkinter; print(sys.version)"

Hämta installationsskriptet, granska filen i en texteditor och kör önskad version:

Invoke-WebRequest -UseBasicParsing https://raw.githubusercontent.com/tvrdprijatelj/runcom/main/install.ps1 -OutFile runcom-install.ps1

# Aktuella rättningar:
powershell -ExecutionPolicy Bypass -File .\runcom-install.ps1 -Ref main

# Eller: senaste publicerade release:
powershell -ExecutionPolicy Bypass -File .\runcom-install.ps1

-ExecutionPolicy Bypass gäller PowerShell-processen som startas av kommandot. Installationskommandot ändrar inte datorns permanenta körpolicy. Normalt behövs inga administratörsrättigheter för installationen i din användarmapp.

3. Starta, hitta och uppdatera appen

Linux och macOS

På Linux kan du söka efter Runcom i programmenyn efter installationen. Om menyn inte uppdateras direkt kan du behöva logga ut och in. På Linux och macOS kan du även starta från terminalen. Om du inte har ändrat installationsplatsen eller XDG_DATA_HOME, använd:

~/.local/share/runcom/runcom

Du kan köra samma kommando igen nästa gång. Om du har valt en annan plats använder du sökvägen som installationsskriptet skriver ut. Inställningen XDG_DATA_HOME påverkar standardmappen.

Windows

Sök efter Runcom i Start-menyn eller dubbelklicka på Runcom-genvägen på skrivbordet. Om genvägen inte kunde skapas kan du starta från PowerShell:

& "$env:LOCALAPPDATA\Runcom\venv\Scripts\python.exe" "$env:LOCALAPPDATA\Runcom\runcom.py"

Uppdatera

  1. Spara ändringar och stäng Runcom.
  2. Hämta ett nytt installationsskript enligt föregående avsnitt.
  3. Kör det igen med samma installationsplats och önskat versionsargument.
  4. Starta appen på nytt. Egna skript ligger separat i din skriptmapp och ersätts inte av en vanlig installation.

Välj en annan installationsplats

# Linux/macOS, gäller detta installationskommando:
RUNCOM_INSTALL_DIR="$HOME/Program/Runcom" bash runcom-install.sh --ref main

# Windows PowerShell:
powershell -ExecutionPolicy Bypass -File .\runcom-install.ps1 -Ref main -InstallDir "$env:USERPROFILE\Program\Runcom"

Kör direkt från källkoden

Hämta repot som ZIP eller klona det, packa upp och öppna en terminal i mappen där runcom.py ligger. Kör python3 runcom.py på Linux/macOS eller py -3 runcom.py på Windows. Tkinter behövs även då.

5. Skapa och kör ditt första skript

  1. Tryck Ny eller Ctrl + N. På macOS fungerar även Command.
  2. Skriv ett filnamn med rätt filändelse: exempelvis hello.py, hello.sh, hello.ps1 eller hello.cmd. Utan en punkt lägger Runcom till .sh på Linux/macOS eller .bat på Windows.
  3. Appen skapar filen direkt i aktuell mapp och öppnar en mall. Om filnamnet redan finns behöver du välja ett annat.
  4. Ersätt texten med ett av exemplen nedan.
  5. Spara med Ctrl + S.
  6. Tryck F5 eller Kör här. Läs resultatet och slutkoden i utdatapanelen.

Python: alla tre systemen

Spara som hello.py:

print("Hej från Runcom!")
for nummer in range(1, 4):
    print(f"Steg {nummer} av 3")

Bash: Linux och macOS

Spara som hello.sh:

#!/usr/bin/env bash
set -euo pipefail
printf "Hej %s!\n" "$(whoami)"
printf "Aktuell mapp: %s\n" "$PWD"

PowerShell: Windows

Spara som hello.ps1:

Write-Host "Hej från Runcom!"
Get-Date
Write-Host "Aktuell mapp: $(Get-Location)"

Batch: Windows

Spara som hello.cmd:

@echo off
echo Hej fran Runcom!
echo Aktuell mapp: %CD%

Exemplen ovan skriver bara text. Vilka åtgärder ett annat skript utför bestäms av dess kod.

6. Välj rätt sätt att köra

Kör här — F5

Använd detta när skriptet kan köras utan att du skriver något medan det arbetar. Standardutdata och standardfel visas i samma panel. En körning åt gången kan vara aktiv i appen. Ändringar sparas innan körningen startas; om filen ännu inte har något namn öppnas Spara som.

Skriptets arbetsmapp är mappen där skriptfilen ligger. En relativ sökväg som data.txt utgår alltså från den mappen. Python-skript använder samma Python-installation eller virtuella miljö som kör Runcom.

Inmatning är avstängd i appens utdatapanel. input(), read, Read-Host, lösenordsfrågor och liknande kan därför misslyckas eller få slut på indata.

Kör i terminal — F6

Använd detta för interaktiva skript. Exempel: skapa fraga.py med koden nedan och tryck F6 i stället för F5.

namn = input("Vad heter du? ")
print(f"Hej {namn}!")

På Linux behövs en installerad terminal som appen kan hitta, exempelvis gnome-terminal, konsole, xfce4-terminal, kitty, alacritty eller xterm. På macOS används Terminal. Windows startar ett separat konsolfönster. Hur länge ett Windows-fönster stannar öppet beror på skripttypen; Python-fönstret kan stängas när skriptet är klart.

Kör med sudo… — Linux/macOS

Knappen startar skriptet i en terminal via sudo. Terminalen sköter eventuell autentisering. Lösenordstecken visas normalt inte när du skriver. Runcom samlar inte in eller sparar sudo-lösenordet. Du behöver ett konto som får använda sudo.

Kör som admin — Windows

Windows visar sin UAC-fråga. Om du godkänner körs skriptet med administratörsrättigheter i ett separat fönster. Avbryter du frågan rapporterar appen att starten avbröts eller misslyckades.

Vad stoppar Stoppa?

Stoppa gäller körningen som startats med Kör här. På Unix skickas först en avslutningssignal till processgruppen och därefter en tvingad stoppsignal om den fortfarande behövs. På Windows används taskkill för processträdet. Ett separat terminal- eller administratörsfönster styr du i det fönstret, exempelvis med Ctrl+C.

Tolka slutkoden

Kod 0 betyder vanligtvis att programmet lyckades. En annan kod anger normalt ett fel eller avbrott, men betydelsen bestäms av programmet. Läs feltexten ovanför slutkoden; Runcom gör inte en automatisk analys av alla felkoder.

7. Spara, byta filer och hantera mappar

Spara och Spara som

Spara skriver till aktuell fil. Spara som låter dig välja en annan plats eller ett annat namn. Om en sådan sparning misslyckas behåller appen kopplingen till den tidigare filen. Att bara ändra filändelsen översätter inte skriptets kod till ett nytt språk.

Appen kodar innehållet innan originalet ersätts. Ett kodningsfel eller fel vid filersättningen ska därför lämna originalet intakt. Ändras filen av ett annat program, eller tas den bort sedan du öppnade den, får du bekräfta innan du skriver över eller återskapar den. Om du vill undersöka en extern ändring först: avbryt sparningen och spara din egen text under ett annat namn.

Osparade ändringar

När du byter fil, skapar en annan fil, byter mapp eller stänger appen kan du välja att spara, kasta ändringarna eller avbryta åtgärden. Avbryt låter dig fortsätta redigera.

Filkodning

Python- och Unix-filer använder UTF-8. Windows-batch använder systemets OEM-teckentabell. PowerShell-filer sparas som UTF-8 med BOM för kompatibilitet med Windows PowerShell 5.1. En batchfil kan inte alltid innehålla alla emoji eller andra Unicode-tecken; välj exempelvis Python eller PowerShell om du behöver sådana tecken.

Mappar och sökning

Standardmappen för skript är ~/skript, alltså mappen skript i din hemkatalog. Appens installationsmapp och skriptmappen är olika saker. Öppnar du en fil från en annan mapp visar fillistan den mappen. Listan visar filer i just den mappen, inte en rekursiv lista över alla undermappar.

Om en fil inte syns: töm sökfältet, kontrollera vald mapp och tänk på att namn som börjar med en punkt döljs. Nya filer och mappbyten rensar sökfiltret. Ta bort-knappen flyttar inte filen till papperskorgen; den tar bort filen permanent efter bekräftelse.

9. Vanliga frågor — FAQ

Varför får jag No module named tkinter?

Tkinter saknas i Python-installationen som kör appen. På Arch installerar du tk; på Ubuntu/Debian python3-tk och på Fedora python3-tkinter. På Windows/macOS behöver Python installeras med Tcl/Tk. Det räcker inte att köra pip install tkinter.

Varför går det inte att skapa en virtuell miljö?

På Ubuntu/Debian kan python3-venv saknas. Installera det och försök igen. Om Python har uppgraderats sedan en gammal Runcom-installation kan den gamla miljön vara trasig; installationsskriptet kontrollerar miljön och försöker återskapa den när den inte fungerar. Läs feltexten om det fortfarande misslyckas.

Varför nämner installationen /tmp och mappen försvinner?

Det tyder på att du har kört ett gammalt installationsskript. Använd kommandona i avsnittet Installation för att hämta ett nytt runcom-install.sh. Den nya installationen sparas i din användarmapp. Kör inte samma gamla fil igen bara för att en nyare fil också finns i Downloads.

Varför får jag en äldre app trots att repot är uppdaterat?

En publicerad release och aktuell källkod på main kan skilja sig. Välj Aktuella rättningar (main) på sidan eller använd --ref main respektive -Ref main. Utan argument hämtar installationsskripten senaste publicerade release.

Varför händer inget när skriptet ställer en fråga?

Kör här kan inte ta emot tangentbordsinmatning. Kör samma skript med F6 i en terminal. Det gäller exempelvis Python input(), Bash read och PowerShell Read-Host.

Varför hittar skriptet inte ett program eller ett Python-paket?

Runcom installerar inte automatiskt allt som dina egna skript behöver. Kontrollera att kommandot finns på PATH. Ett Python-skript körs med Runcoms Python-miljö; paket installerade i en annan miljö behöver inte finnas där. Installera paket i rätt miljö eller starta Runcom från den miljö du vill använda.

Varför hittas inte data.txt eller en relativ sökväg?

Körningen utgår från skriptfilens mapp. Lägg filen där, ange en korrekt relativ sökväg eller använd en absolut sökväg. Installationsmappen eller terminalens tidigare mapp är inte automatiskt skriptets arbetsmapp.

Varför står det Filtypen stöds inte?

Kontrollera filändelsen och innehållet. Windows stöder .bat, .cmd, .ps1 och .py. På Linux/macOS stöds .py, .sh, .bash och textskript med en giltig shebang. Att döpa om en vanlig textfil gör inte texten till körbar kod.

Varför saknas PowerShell eller en terminal?

På Windows behöver PowerShell eller pwsh finnas på PATH. På Linux behöver F6 en av de terminaler som Runcom söker efter. Installera en terminal, starta om appen om PATH ändrats och försök igen. Kör här fungerar utan separat terminal för icke-interaktiva skript.

Varför kan en batchfil inte ligga i en sökväg med procenttecken?

cmd kan expandera uttryck mellan procenttecken som miljövariabler även i vissa citerade sökvägar. Runcom avvisar därför sådana batchsökvägar med en förklaring. Flytta filen eller byt namn på filen/mappen så att sökvägen inte innehåller %. Mellanslag och & hanteras med citering.

Varför får jag Permission denied eller Access denied?

Kontrollera rättigheterna till filen och mappen. Kontrollera också om skriptets egen åtgärd kräver andra rättigheter. På Linux/macOS kan Kör med sudo användas när skriptet behöver det; på Windows finns Kör som admin. Att köra ett skript som administratör löser inte automatiskt felaktiga sökvägar eller programfel.

Varför visas inte all gammal utdata?

Runcom begränsar både kön och den synliga mängden utdata för att hålla appen hanterbar. Äldre text i panelen kan därför försvinna. Om du behöver en fullständig logg bör skriptet skriva en egen loggfil, eller så kan du köra i en terminal och omdirigera utdata där.

Stoppar knappen även externa terminalfönster?

Nej. Stoppa är kopplad till körningen i appen. Använd Ctrl+C eller avsluta programmet i det externa fönstret. Fristående eller avsiktligt frånkopplade processer kan behöva avslutas separat.

Kan jag läsa hjälpen utan internet?

Den uppdaterade installationen kopierar med hjälpsidorna. Appens Hjälp-knapp använder den lokala sidan när den finns. Om du bara har hämtat runcom.py öppnas webbversionen i stället. Länkar till nedladdningar, GitHub och python.org behöver internet.

Varför öppnas ingen webbläsare när jag trycker Hjälp?

Kontrollera att en standardwebbläsare är inställd. Appen visar en adress om den inte kan starta webbläsaren. Du kan öppna https://tvrdprijatelj.github.io/runcom/help.html manuellt. F1 och Hjälp-knappen gör samma sak.

Hur avinstallerar jag Runcom?

Stäng appen och ta bort dess installationsmapp: normalt ~/.local/share/runcom på Linux/macOS eller %LOCALAPPDATA%\Runcom på Windows. På Windows tar du även bort Runcom-genvägarna på skrivbordet och i Start-menyn. Start-menyns genväg ligger normalt i %APPDATA%\Microsoft\Windows\Start Menu\Programs\Runcom.lnk. På Linux tar du bort ~/.local/share/applications/runcom.desktop, eller motsvarande fil under din anpassade XDG_DATA_HOME. Behåll ~/skript och andra mappar med dina egna skript om du vill spara dem. Om du valt en annan installationsplats tar du bort den platsen i stället.

Hur rapporterar jag ett fel som inte finns här?

Beskriv vilket operativsystem du använder, Python-versionen, hur Runcom startades, vad du klickade på och vad som hände. Kopiera exakt feltext och bifoga gärna ett litet exempel som återskapar felet. Rapportera via GitHub Issues. Ta bort lösenord, nycklar och annan privat information från loggar och skript innan du publicerar dem.

10. Felsök steg för steg

  1. Kontrollera versionen du hämtade. Är det en äldre release eller aktuell main? Uppdatera från rätt alternativ och stäng/starta appen.
  2. Starta från terminalen. Kör python3 runcom.py eller py -3 runcom.py från källkodsmappen för att se startfel som annars kan döljas av en genväg. Vid en installerad app använder du dess Python-sökväg och programfil.
  3. Kontrollera Python och Tkinter. Kör testet nedan med samma Python som du använder för appen.
python3 -c "import sys, tkinter; print(sys.version); print(tkinter.TkVersion)"
# Windows:
py -3 -c "import sys, tkinter; print(sys.version); print(tkinter.TkVersion)"
  1. Prova ett minimalt skript. Använd hello.py från guiden. Om det fungerar men ditt eget skript inte fungerar, jämför vilka program, filer, paket och rättigheter ditt skript behöver.
  2. Välj rätt körläge. Testa F6 om skriptet ber om något. Kontrollera arbetsmappen och slutkoden.
  3. Kontrollera filåtkomst. Försök Spara som till en mapp du äger. Kontrollera om en annan editor ändrar samma fil.
  4. Samla felet. Notera alla steg och exakt feltext. Använd FAQ ovan eller rapportera ett reproducerbart exempel.

Vid fel som no display name eller couldn't connect to display saknas en grafisk session som Tkinter kan använda. Runcom behöver ett grafiskt skrivbord; en vanlig SSH-session utan tillgång till en grafisk display räcker inte.
