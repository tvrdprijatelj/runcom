1. What is Runcom?

Runcom is a script editor for Linux, macOS, and Windows. The first time it opens, a graphical dialog asks you to choose Swedish or English. The choice is saved and can later be changed in Settings. Runcom combines a file list, code editor, output panel, and interactive terminal. The app opens on the Scripts tab. Its logo and color theme are used throughout the interface; the terminal has a black background and green text.

SystemSupported scripts
Linux and macOSPython, Bash, and other text scripts with a valid shebang.
WindowsBatch (.bat/.cmd), PowerShell (.ps1), and Python (.py).

Runcom requires Python 3.8 or later with Tkinter. Start on the download page for operating-system-specific installation commands.

2. The interface

AreaPurpose
ScriptsLists files in the selected folder. Select a file and click Edit selected script to open it in the editor. Double-click or press Enter to run it directly.
EditorWrite and edit your script here. A dot before the filename indicates unsaved changes.
OutputShows output and the exit code from Run in app. This panel does not accept keyboard input.
TerminalA persistent interactive terminal with a black background and green text. Use it for normal commands and sudo.

Drag the dividers to resize the file list, editor, and output panel.

3. Create and run your first script

  1. Select New or press Ctrl+N.
  2. Enter a name such as hello.py or hello.sh. Runcom creates a template for that language.
  3. Edit the code and save with Ctrl+S.
  4. Press F5 to run it inside the app. Output and the exit code appear below the editor.
#!/usr/bin/env python3

name = input("What is your name? ")
print(f"Hello, {name}!")

The example above requires input, so run it in a separate terminal with F6.

4. Choose the right run mode

ModeUse it for
Run in app (F5)Non-interactive scripts. Output appears in the app and the Stop button can terminate the process.
Run in terminal (F6)Scripts that request input or use interactive or full-screen terminal programs.
Run with sudo (F8)Linux/macOS: runs the entire script with sudo in the built-in terminal.
Run as administratorWindows: opens the system UAC prompt and runs the script with administrator privileges.

If a Unix shell script contains a real sudo command, Runcom detects it and automatically sends the entire script through the secure sudo flow in the terminal. Comments and ordinary text should not trigger this behavior.

5. Built-in terminal and sudo

The terminal

Open the Terminal tab or press F7. Type commands directly in the terminal area. Ctrl+C interrupts a command and Ctrl+Shift+V pastes. Restart terminal creates a fresh session.

Graphical sudo authentication

On Linux and macOS, Runcom requests your sudo password in a graphical masked dialog when the app opens. The password is sent directly to the system sudo process through the terminal session. It is never stored in a file, environment variable, or command line. An incorrect password displays a clear error and asks you to try again; an accepted password is confirmed in the status bar. No dialog appears if passwordless sudo is configured.

Sudo authorization is kept active while Runcom is open. You can inspect its status, enable it again, or disable session maintenance in Settings or on the Terminal tab. Cancelling the password dialog does not prevent you from using Runcom without sudo.

6. Files, folders, and safe saving

Open can switch to the opened file's folder. Change folder chooses the folder shown in the file list. Save as creates a new file association. Delete permanently removes the selected file after confirmation.

Runcom warns about unsaved changes and files modified outside the app. Python and Unix files use UTF-8. PowerShell uses UTF-8 with a BOM, while batch files use the Windows OEM encoding.

8. Troubleshooting

Why does nothing happen when my script requests input?

Run in app has no standard input. Use F6 or the built-in terminal for programs that call Python input(), Bash read, or similar functions.

Why is sudo not working?

Check that sudo is installed and that your account is allowed to use it. Open Settings and select Enable sudo. You can retry after cancelling or entering an incorrect password.

Why does the app fail to start?

Verify that Python 3.8+ and Tkinter are installed. Ubuntu/Debian commonly use python3-tk, Arch uses tk, and Fedora uses python3-tkinter.

Why can my script not find a file or program?

The script's working directory is the folder containing the script. Check relative paths and verify that external programs are available on PATH in Runcom's environment.

Why is older output missing?

Runcom limits visible output to keep the interface responsive. Have the script write a log file if you need a complete history.

9. Update or uninstall

An installed copy of Runcom automatically checks for the latest published release at startup and installs it in the background without confirmation dialogs. Your scripts and language choice are preserved. The new version is used the next time the app starts. The Update button remains available for a manual check.

Uninstall from Settings → Uninstall Runcom. Application files and shortcuts are removed, but your own scripts are kept. If the option is unavailable or the installation is older, follow the operating-system-specific steps on the uninstall page.
